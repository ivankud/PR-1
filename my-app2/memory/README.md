# Банк памяти проекта

Этот каталог содержит структурированную информацию о проекте для быстрого восстановления контекста.

## Структура

| Файл | Содержимое |
|------|-----------|
| `architecture.md` | Общая архитектура проекта, слои приложения, стек |
| `state.md` | Управление состоянием: EditorContext, reducer, все действия |
| `utils.md` | Все утилиты: jsonUtils, anchors, primitiveRenderer, functionRunner, formLoader, sizeUtils, auth |
| `components.md` | Все UI-компоненты и их назначение |
| `data-models.md` | Модели данных: форма, примитив, шаблон, контекст, функции |
| `patterns.md` | Ключевые паттерны: добавление действий, примитивов, события, история |
| `decisions.md` | Архитектурные решения и их обоснование |

## Правила использования

1. **Перед началом задачи** — прочитать `architecture.md` и `data-models.md` для восстановления контекста.
2. **При работе с состоянием** — обратиться к `state.md`.
3. **При работе с утилитами** — обратиться к `utils.md`.
4. **При работе с компонентами** — обратиться к `components.md`.
5. **При следовании паттернам** — обратиться к `patterns.md`.
6. **При принятии решений** — проверить `decisions.md`, чтобы не противоречить существующим.

## Обновление

- Файлы обновляются при значительных изменениях в архитектуре.
- Новые архитектурные решения добавляются в `decisions.md`.
- Новые паттерны добавляются в `patterns.md`.
