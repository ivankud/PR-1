## 1. Что такое функции и события

### Пользовательские функции

Это JavaScript-функции, которые вы определяете прямо в конструкторе для конкретной веб-формы. Функции хранятся в JSON формы и могут:

- Читать данные из **контекста формы** (inline — встроенные данные или данные, загруженные по URL)
- Выполнять любые действия: валидацию, показ сообщений, манипуляции с DOM
- Возвращать значения

### События

События — это точки взаимодействия пользователя с формой и её элементами:

- **События формы**: `onOpen` (открытие формы), `onSubmit` (отправка формы)
- **События элементов**: `click`, `change`, `input`, `focus`, `blur`, `mouseenter`, `mouseleave`

Событие **привязывается к функции** — при наступлении события функция вызывается с контекстом формы.

## 2. Создание пользовательских функций

### Шаг 1. Откройте редактор формы

Нажмите «✏️ Редактор форм» в навигационном меню.

### Шаг 2. Перейдите на вкладку «Функции»

В **левой панели** редактора откройте вкладку **«Функции»** (третья вкладка рядом с «Примитивы» и «Слои»).

### Шаг 3. Добавьте функцию

Нажмите кнопку **«➕ Добавить функцию»**.

### Шаг 4. Заполните форму

Появятся поля:

| Поле | Описание | Пример |
|------|----------|--------|
| **Имя** | Уникальное имя функции (на английском) | `validateEmail` |
| **Описание** | Что делает функция (необязательно) | `Проверка корректности email` |
| **Код** | Тело JavaScript-функции | См. примеры ниже |

### Шаг 5. Сохраните

Нажмите **«Сохранить»**. Функция появится в списке.

## 3. Сигнатура функции и доступ к контексту

### Сигнатура (что доступно внутри функции)

```js
function myFunction(context) {
  // context — объект с данными формы
}
```

### Объект `context`

Параметр `context` содержит **все данные контекста формы**:

```js
function showUserName(context) {
  // Если контекст формы содержит:
  // { "user": { "name": "Иван", "email": "ivan@example.com" } }
  return 'Здравствуйте, ' + context.user.name + '!';
}
```

### Событийные данные

При вызове через событие, в `context` дополнительно добавляются:

```js
function handleClick(context) {
  // context.event — информация о событии
  console.log('Событие:', context.event.type);        // "click"
  console.log('Значение:', context.event.value);       // значение input
  console.log('Элемент:', context.primitiveName);      // имя примитива
}
```

### Полный набор доступных данных

| Свойство | Тип | Описание |
|----------|-----|----------|
| `context` | объект | Данные формы (inline или загруженные по URL) |
| `context.event` | объект | Информация о событии (`type`, `value`, `target`) |
| `context.primitiveId` | строка | ID примитива, вызвавшего событие |
| `context.primitiveName` | строка | Имя примитива |

## 4. События формы

### Как привязать функцию к событию формы

1. В редакторе **уберите выделение** элементов (кликните на пустое место холста)
2. В **правой панели** перейдите на вкладку **«События»**
3. Для нужного события выберите функцию в выпадающем списке

### Поддерживаемые события формы

| Событие | Описание |
|---------|----------|
| `onOpen` | Вызывается при открытии формы (после загрузки контекста) |
| `onSubmit` | Вызывается при отправке формы |

### Пример привязки

1. Уберите выделение → правая панель → вкладка **«События»**
2. Для `onOpen` выберите функцию `initForm`
3. Для `onSubmit` выберите функцию `submitData`

## 5. События элементов

### Как привязать функцию к событию элемента

1. Кликните по элементу на холсте (например, кнопке)
2. В **правой панели** перейдите на вкладку **«События»**
3. Для нужного события выберите функцию

### Поддерживаемые события элементов

| Событие | Описание |
|---------|----------|
| `click` | Клик по элементу |
| `change` | Изменение значения (для input, select, checkbox) |
| `input` | Ввод текста (каждый символ) |
| `focus` | Получение фокуса |
| `blur` | Потеря фокуса |
| `mouseenter` | Наведение мыши |
| `mouseleave` | Уход мыши |

### Пример привязки

1. Выберите поле ввода email
2. Вкладка **«События»** → для события `blur` выберите функцию `validateEmail`
3. Теперь при потере фокуса полем email будет вызвана валидация

## 6. Примеры готовых функций

### Валидация email

```js
function validateEmail(context) {
  const email = context.event?.value || '';
  if (!/^[^@\s]+@[^@\s]+\.[^@\s]+$/.test(email)) {
    alert('Введите корректный email!');
  }
}
```

### Показ приветствия

```js
function greetUser(context) {
  const name = context.user?.name || 'гость';
  alert('Здравствуйте, ' + name + '!');
}
```

### Подсчёт символов в поле

```js
function countChars(context) {
  const value = context.event?.value || '';
  const counter = document.getElementById('char-counter');
  if (counter) counter.textContent = 'Символов: ' + value.length;
}
```

### Отправка данных на сервер

```js
function submitData(context) {
  fetch('https://api.example.com/submit', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(context)
  })
    .then(res => res.json())
    .then(data => {
      alert('Данные отправлены! ID: ' + data.id);
    })
    .catch(err => {
      console.error('Ошибка:', err);
      alert('Ошибка отправки данных');
    });
}
```

### Динамическое изменение контекста

```js
function updateUserEmail(context) {
  // context.event.value — новое значение из поля ввода
  context.user.email = context.event?.value || '';
  console.log('Обновлённый контекст:', context);
}
```

## 7. Структура JSON

### Функции и события в JSON формы

```json
{
  "id": "example-form",
  "name": "Моя форма",
  "context": {
    "source": "inline",
    "inline": {
      "user": {
        "name": "Иван Петров",
        "email": "ivan@example.com"
      }
    }
  },
  "functions": [
    {
      "id": "fn-1785965333048-oacl3a62o",
      "name": "validateEmail",
      "description": "Проверка email",
      "code": "const email = context.event?.value || ''; if (!/^[^@\\s]+@[^@\\s]+\\.[^@\\s]+$/.test(email)) { alert('Некорректный email'); }"
    },
    {
      "id": "fn-1785966018906-b5i1z8otm",
      "name": "greetUser",
      "description": "Приветствие",
      "code": "alert('Привет, ' + (context.user?.name || 'гость') + '!');"
    }
  ],
  "events": {
    "onOpen": "greetUser",
    "onSubmit": "validateEmail"
  },
  "children": [
    {
      "id": "prim-3",
      "type": "input",
      "name": "Поле email",
      "events": {
        "blur": "validateEmail"
      }
    }
  ]
}
```

### Описание полей

| Поле | Расположение | Описание |
|------|-------------|----------|
| `functions` | Уровень формы | Массив функций. Каждая: `id`, `name`, `description`, `code` |
| `events` | Уровень формы | Объект: `{ "onOpen": "fnName", "onSubmit": "fnName" }` |
| `events` | Уровень примитива | Объект: `{ "click": "fnName", "blur": "fnName" }` |

## 8. Ограничения и безопасность

### Как исполняются функции

- Функции компилируются через `new Function('context', code)`
- Каждая функция получает один аргумент — объект `context`
- Функции выполняются в браузере при просмотре/предпросмотре формы

### Что нужно знать

- **Нет доступа к React-состоянию** — функции работают как обычные JS-функции
- **Нет доступа к хукам React** — нельзя использовать `useState`, `useEffect`
- **Доступен весь браузерный API** — `document`, `window`, `fetch`, `console` и т.д.
- **Ошибки в коде** функции логируются в консоль браузера (`console.error`)

### Рекомендации по безопасности

- Не выполняйте пользовательский код вне изолированной среды (если формы используют сторонний ввод)
- Ограничивайте доступ к чувствительным операциям (например, отправка данных) через проверку
- Валидируйте пользовательский ввод внутри функций

## 9. Чек-лист

### При создании функции

- [ ] Имя функции указано на английском (латиницей)
- [ ] Имя уникально (не совпадает с другими функциями)
- [ ] Код — валидный JavaScript
- [ ] Используется параметр `context` для доступа к данным формы

### При привязке события к функции

- [ ] Функция создана во вкладке «Функции»
- [ ] Выбран элемент (или форма «ничего не выбрано»)
- [ ] Открыта вкладка «События» в правой панели
- [ ] Для нужного события выбрана функция
- [ ] Проверен предпросмотр формы — событие срабатывает

### При сохранении формы

- [ ] Функции сохранены в JSON формы (поле `functions`)
- [ ] События сохранены в JSON (поля `events`)
- [ ] JSON-файл формы содержит все функции и связи корректно
